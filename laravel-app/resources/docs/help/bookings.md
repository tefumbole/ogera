# Bookings & Rentals

The **Rental Module** (also called Booking Module in some roles) handles equipment rentals: create a booking, attach products with start/end times, send contracts, and schedule reminders.

![Create booking](/public/help/screenshots/09-booking-create.png)

## Create a booking

1. Sidebar → **Rental Module** → **Booking Create**.
2. Choose **Customer**, **Biller**, and **Warehouse**.
3. Add equipment:
   - Search by **product name** or **barcode**, or
   - Scan a barcode — it is added to the booking lines automatically.
4. Set **start** and **end** date/time for each line (return deadline).
5. Review totals, payment if any, then **Submit**.

> Select customer and warehouse first. The product box will remind you if they are missing.

## Booking list

![Booking list](/public/help/screenshots/10-booking-list.png)

1. Sidebar → **Rental Module** → **Booking List**.
2. Open **Action** on a row for contract, delivery note, WhatsApp, payments, edit, and print.
3. Names should appear with phone numbers in contact menus — not numbers alone.

## Booking requests

**Booking Request** shows bookings that came from the public website. Review, confirm, or follow up from here. A badge on the menu shows how many are waiting.

## Contracts & signatures

| Menu | Meaning |
|------|---------|
| **Awaiting Signature** | Contract sent; client has not signed yet |
| **Pending Review** | Client signed; staff should review |
| **Signed Contracts** | Fully signed rental agreements |

Clients sign through a secure link (WhatsApp / email). Staff signatures on rental PDFs use the signature saved on the user account.

## Reminders

**Booking Reminder** lists reminders due soon. You can schedule a WhatsApp reminder when creating or editing a booking. The system only sends reminders that are still recent — very old overdue reminders are not blasted out after a long outage.

## Booked products & calendar

- **Booked Products** — every line still out on rent.
- **Booking Calendar** — day view of rental activity (under Booking Report / Calendar).

## Returns

When equipment comes back, mark the line as returned from the booking / booked products flow so late notices stop and stock is freed.
