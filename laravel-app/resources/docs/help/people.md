# People & Customers

**People** holds customers, suppliers, billers, and system users. Correct phone numbers matter — WhatsApp and booking messages use them.

![Customer list](/public/help/screenshots/11-customers.png)

## Customer list

1. Sidebar → **People** → **Customer List**.
2. Search by name, phone, or email.
3. **Action** → view, edit, deposits, payments, or delete (if allowed).

## Add a customer

1. Sidebar → **People** → **Add Customer**.
2. Enter **Name** and **Phone** (with country code when possible, e.g. `2507…` for Rwanda).
3. Optional: email, address, customer group, tax number.
4. Save.

> Country flags in lists need a modern browser with emoji colour fonts. Abbreviated country codes (RW, CM) still mean the same country if flags do not render on a machine.

## Customer groups

Sidebar → **Settings** (or People, depending on permissions) → **Customer Group** to price differently for wholesale / VIP groups. Assign the group on the customer form.

## Users (staff)

1. Sidebar → **People** → **User List**.
2. **Add User** with name, email/username, role, and phone.
3. Optional: draw a **signature** on the pad, or choose **Send for Signature** so the person signs remotely via a link.
4. From the user list **Action** menu you can also **Send for Signature** later.

Staff signatures appear on sales, quotations, and rental documents.

## Suppliers & billers

- **Supplier List** — vendors you buy from (purchases).
- **Biller List** — the company identity printed on invoices (logo, address, VAT).

## Export / import

**People → Export / Import People** moves customer CSV files in or out. Download the sample file first so columns match.
